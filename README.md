# 智能门锁（51 单片机 + LCD1602 + 4×4 键盘 + 继电器）

## 1. 功能

| 功能 | 说明 |
| --- | --- |
| 密码开锁 | 6 位密码，输满 6 位自动校验，也可按 `#` 手动提交 |
| 退格 | `*` 删除上一位 |
| 修改密码 | `A` 进入，先验证旧密码，再输入两次新密码 |
| 取消 | `B` 退出修改密码，回到待机界面 |
| 防试探 | 连续输错 3 次锁定 30 秒并倒计时 |
| 自动上锁 | 开锁后继电器吸合 5 秒，LCD 倒计时，时间到自动断开 |
| 输入超时 | 15 秒无按键自动清除已输入内容，防止别人接着输 |
| 上电安全 | 上电后继电器保持断开，复位瞬间不会误开锁 |

LCD 显示（英文，1602 没有中文字库）：

```
SMART LOCK            DOOR OPENED           ACCESS DENIED
Enter password        Relock in 05s         Tries left: 2
```

```
LOCKED OUT            Old password:         New password:
Wait 30s              PWD: ******           PWD: ******
```

## 2. 硬件接线

| 器件 | 引脚 | 说明 |
| --- | --- | --- |
| LCD1602 RS | P2.6 | |
| LCD1602 RW | P2.5 | 用于读忙标志，必需 |
| LCD1602 EN | P2.7 | |
| LCD1602 D0~D7 | P0 | P0 需要上拉排阻（开发板一般自带） |
| 键盘列 C1~C4 | P3.7 ~ P3.4 | 依次输出低电平扫描 |
| 键盘行 R1~R4 | P3.3 ~ P3.0 | 输入，按下读到低电平 |
| 继电器 IN | P2.0 | 继电器模块 VCC/GND 接 5V/地，与单片机共地 |
| 晶振 | 11.0592MHz | 12MHz 需改 `config.h` 里的 `FOSC` |

注意：这块开发板的 8 个 LED 也接在 P2 上（LED6~LED8 正好是 LCD 控制线，LED1 正好是 P2.0）。
用 LCD 和继电器时，请把 **LED1、LED6、LED7、LED8 的跳线帽拔掉**，否则会互相干扰。

## 3. 文件说明

| 文件 | 作用 |
| --- | --- |
| `config.h` | **所有可调参数都集中在这里**（密码位数、次数、时间、继电器极性、晶振） |
| `main.c` | 门锁业务逻辑：状态机、界面、开锁/锁定/改密流程 |
| `lcd.c / lcd.h` | LCD1602 驱动（读忙标志、限幅、字符串不换行溢出） |
| `keyboard.c / keyboard.h` | 4×4 矩阵键盘扫描 + 15ms 消抖 + 松手检测 |
| `delay.c / delay.h` | 定时器 0 产生 1ms 节拍，提供 `delay_ms()` / `tick_get()` |
| `jdq.c / jdq.h` | 继电器（电磁锁）控制，极性可配置 |
| `led.c / led.h` | 板载 LED 驱动（本程序未使用，保留方便扩展） |

## 4. 参数配置

打开 `config.h`：

```c
#define FOSC            11059200UL   // 晶振频率
#define PWD_LEN         6            // 密码位数
#define PWD_DEFAULT     "123456"     // 出厂密码
#define MAX_TRY         3            // 输错几次锁定
#define LOCKOUT_SEC     30           // 锁定秒数
#define UNLOCK_SEC      5            // 开锁后自动上锁秒数
#define IDLE_TIMEOUT_MS 15000        // 输入超时
#define LOCK_ACTIVE_LOW 1            // 1=低电平吸合, 0=高电平吸合
```

> **继电器极性一定要确认**：如果上电后继电器立刻吸合（锁一直开着），把
> `LOCK_ACTIVE_LOW` 改成 `0`，或者把继电器模块的 `IN` 接到高电平有效的另一端。
> 默认选低电平有效，是因为 51 复位后 IO 是高电平，这样上电瞬间锁是关着的。

## 5. 键盘布局

程序默认按标准 4×4 薄膜键盘的丝印映射：

```
1 2 3 A
4 5 6 B
7 8 9 C
* 0 # D
```

如果手上的键盘丝印不一样（例如行列是反的），只改 `keyboard.c` 里的 `key_map[16]` 表即可，
不用动业务代码。

## 6. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 上电锁就吸合 | 继电器极性反了，改 `LOCK_ACTIVE_LOW` |
| 继电器完全不动作 | 先用万用表量 P2.0：开锁时应为低电平。若模块是高电平触发，51 的高电平输出电流很小（几十 µA），带不动模块，需换低电平触发模块或加一级三极管 |
| 按键值都不对 | 键盘丝印不同，改 `key_map`；或用万用表确认行列接法 |
| LCD 一片方块 / 不显示 | 对比度电位器没调；检查 P0 上拉排阻和 RS/RW/EN |
| LCD 显示乱码 | 初始化时序问题已处理；若仍异常，检查 RW 是否真的接到 P2.5 |
| 倒计时偏快/偏慢约 8% | 晶振不是 11.0592MHz，改 `FOSC` |
| 编译提示代码超 2KB | 你的 Keil 是评估版（0x800 限制），当前占用约 87%，改用正式版即可 |

## 7. 相比原始代码修复的问题

1. **输入计数从不自增**：`intput_cnt` 没有 `++`，永远停在 0，密码永远不会被校验。
2. **数组越界**：`input_buf[pwd_len]` 只有 6 字节，却要写第 7 个字节（结束符），且先写后判断。
3. **按键返回值判断错误**：`keynum_get()` 无键返回 `0`，`main` 却判断 `0xFF`；而且 `char` 与 `0xFF` 比较永远不成立。
4. **键值没有转 ASCII**：键盘返回 1~16，却直接和 `"123456"` 比较，两者永远不相等。
5. **没有松手检测**：按住一个键会连续触发，`Delay100us(150)` 之后直接返回。
6. **延时函数溢出**：`Delay100us` 里 `unsigned char i = 2 * time`，传 150 时溢出成 44；`while(--j)` 的外层循环也没有重装 `j`。
7. **LCD 时序错误**：EN 先拉高再送数据；清屏只延时 1ms（实际需要 1.64ms）；没有读忙标志；`lcd_setcursor` 有运算符优先级问题；字符串超长会绕到下一行。
8. **LED 的 switch 全部漏了 `break`**：点一个灯会把后面的灯全部点亮。
9. **继电器函数被注释掉**：`lock_open/lock_close` 只有声明没有实现，`app_open_lock()` 里只是写了一行局部函数声明，从来没有真正驱动过继电器。
10. **没有开锁状态管理**：没有自动上锁、错误次数统计、锁定倒计时和改密码流程。

## 9. 可继续扩展

- **密码掉电保存**：密码目前存放在 RAM，断电恢复成 `123456`。加一颗 AT24C02（I2C）即可持久化，改密码后写入、上电时读出校验。
- **蜂鸣器提示**：按键音、开锁成功两短声、错误三长声（注意本板蜂鸣器脚与 LED 共用 P2，先确认丝印）。
- **门磁检测**：加一个霍尔/干簧管到空闲 IO，检测门是否被打开，超时未关报警。
- **防拆报警 / 虚位密码 / 管理员密码**：在 `main.c` 的状态机上继续加分支即可。
